## Brand & Style

This design system establishes an authoritative, precise, and refined visual language tailored for a senior-grade software engineering portfolio. The brand communicates deep technical rigor, pragmatic problem-solving, and architectural discipline. The aesthetic avoids fleeting decorative trends and excessive visual noise in favor of structure, high-legibility typographic hierarchies, crisp borders, and restrained elevation.

The design movement combines **Corporate Modernism** with utilitarian **Developer-Focused Minimalism**. It balances high-contrast dark canvas anchor zones (Hero, Terminal blocks, Footer) with an expansive, clinical light content canvas for case studies, experience chronologies, and skill matrices. The emotional tone evokes reliability, technical mastery, clean execution, and executive readiness.

## Colors

The palette operates on a deliberate dual-zone structural approach:
- **Surface Framing (Dark Anchors):** Deep Navy (`#101827`) frames the terminal-like Hero section and the bottom global Footer, establishing an immediate developer posture. Dark slate variations (`#0B0F19`) serve as elevated surfaces inside dark modules.
- **Main Canvas (Light Surfaces):** Content sections transition directly into Pristine Off-White/Light Grey (`#F8FAFC`), supported by pure White (`#FFFFFF`) card surfaces to maximize reading endurance for long-form case studies.
- **Accent Rhythm:** Royal Blue (`#2563EB`) acts as the primary interactive catalyst and focused semantic marker, shifting to Deep Cobalt (`#1D4ED8`) on hover and active states. Soft blue tints (`#EFF6FF`) are reserved for active pill badges and subtle interactive highlights.
- **Text & Hierarchy:** Headings and key metrics use Deep Slate (`#0F172A`) on light sections (or `#F8FAFC` on dark sections). Supporting descriptions, labels, and timestamps rely on Muted Slate Grey (`#64748B`).
- **Dividers & Structural Rules:** Crisp borders use Neutral Light Slate (`#E2E8F0`) on light surfaces and subtle dark slate lines (`#1E293B`) in dark sections.

## Typography

Typographic scale is structured around `Inter` for prose and navigation, paired with `JetBrains Mono` for meta tags, tech stacks, timestamps, and terminal data representations.

- **Primary Typeface (Inter):** Leverages aggressive negative letter tracking at large sizes (`-0.03em` down to `-0.015em`) to render crisp, authoritative headlines that avoid typographic flabbiness. Body copy maintains neutral tracking and generous proportional line-heights (`1.6x`) to facilitate effortless reading.
- **Monospaced Utility (JetBrains Mono):** Injects authentic developer character. Used strictly for technical attributes, tech-stack tags, commit metadata, and section counters (e.g., `01 // ARCHITECTURE`).
- **Responsive Adjustments:** Hero typography gracefully scales down via explicit mobile tokens, preventing awkward single-word wrapping on 375px–414px viewports.

## Layout & Spacing

The layout is built upon an 8pt vertical spacing cadence and a standard 12-column responsive fluid grid with a maximum content container width of `1200px`.

- **Form Factors:**
  - **Desktop (1024px+):** 12 columns, `1.5rem` (`24px`) gutters, container centered with `2rem` side safety margins. Section padding scales vertically with an airy rhythm of `5rem` to `7rem` (80px to 112px).
  - **Tablet (768px - 1023px):** 8 columns, `1.25rem` (`20px`) gutters, `1.5rem` margins. Multicolumn project layouts collapse into balanced 2-column modules.
  - **Mobile (< 768px):** 4 columns, `1rem` (`16px`) gutters, `1rem` margins. All structural grids collapse into clean single-column stacks.
- **Hybrid Section Flow:** Transitions between the Dark Navy hero (`#101827`) and Light content sections (`#F8FAFC`) occur via horizontal boundaries without decorative wave dividers or angled diagonals. Precision edge alignment and consistent container margins maintain cohesion across both zones.

## Elevation & Depth

This design system avoids heavy blurred drop shadows and hyper-glossy skeuomorphism. Depth is established through **low-contrast structural outlines** augmented by subtle, calibrated ambient occlusion:

- **Baseline Level (Cards & Containers):** Pure white background (`#FFFFFF`) anchored by a crisp `1px` border using `#E2E8F0`. Depth is sustained by an ultra-subtle ambient shadow: `0 1px 3px 0 rgba(15, 23, 42, 0.05), 0 1px 2px -1px rgba(15, 23, 42, 0.04)`.
- **Hovered Elevation:** Interactive cards slightly lift on cursor focus: `0 10px 15px -3px rgba(15, 23, 42, 0.06), 0 4px 6px -4px rgba(15, 23, 42, 0.03)`, accompanied by a border tint shift from `#E2E8F0` to a subtle blue `#BFDBFE`.
- **Floating Overlays (Modals & Navbars):** Fixed navigation ribbons utilize backdrop saturation with high-translucency frosted panels (`rgba(255, 255, 255, 0.88)` on light content, or `rgba(16, 24, 39, 0.85)` within the hero) alongside a bottom structural edge border.
- **Dark Hero Surfaces:** In the dark hero zone, nested code widgets and terminal cards sit directly on `#0F172A` with a subtle outline of `rgba(255, 255, 255, 0.08)`.

## Shapes

The system implements deliberate geometric refinement with Level 2 roundedness (`rounded-lg` base of `0.5rem` / `8px`):

- **Buttons & Form Inputs:** Set to `0.5rem` (`8px`) radius. This maintains crisp geometric edges without feeling severe or overly rounded.
- **Cards & Architectural Surfaces:** Use `0.75rem` to `1rem` (`12px` to `16px`) corner radiuses (`rounded-lg` / `rounded-xl`) to neatly frame dense text and technical metrics.
- **Badges, Tags, & Status Pills:** Feature pill roundedness (`9999px`) to immediately signal interactive metadata and technology categorization distinct from square containers.

## Components

### Buttons
- **Primary:** Filled `#2563EB` background with white text, font `Inter` semibold (14px). Transitions smoothly to `#1D4ED8` on hover. Active state depresses subtly (`scale(0.99)`). Focus states feature an accessible `2px` offset ring in `#2563EB`.
- **Secondary / Outline:** White or transparent fill with a `1px` border in `#E2E8F0` (light context) or `#334155` (dark context), text colored `#0F172A` or `#F8FAFC`. Hovers introduce light slate surface fills (`#F1F5F9`).
- **Icon / Action Buttons:** Square dimensions (`40x40px` or `36x36px`) centering standard developer icons (GitHub, LinkedIn, Terminal, External Link) with micro-transitions on hover.

### Technology Badges & Chips
- Compact height (`24px`), fully rounded pill shape (`9999px`), padding `0.25rem 0.625rem`.
- Set in `JetBrains Mono` (`11px` / `label-sm`).
- **Styling:** Neutral grey background (`#F1F5F9`), subtle `#E2E8F0` border, text `#475569`. Featured skills or active filters use light blue tint (`#EFF6FF`), `#BFDBFE` border, and Royal Blue text (`#2563EB`).

### Project & Case Study Cards
- Crisp white surface (`#FFFFFF`), `1px` border (`#E2E8F0`), padding `1.5rem` to `2rem`.
- Features an organized vertical hierarchy:
  1. Header with mono category marker and live link icon.
  2. Bold project title (`headline-md`).
  3. Concise engineering synopsis (`body-md`).
  4. Technology badge chip rack.
  5. Metrics or architectural takeaway block.
- On hover, the border seamlessly transitions to Royal Blue tint with an ambient lift.

### Professional Experience Timeline
- Vertical linear axis running a continuous `2px` rule in `#E2E8F0`.
- **Nodes:** Dual-ring circular markers (`12px` diameter) filled with white, bordered in Royal Blue (`#2563EB`), anchoring directly at the alignment line of job titles.
- Accompanying content blocks present the timeline date in `JetBrains Mono` (`label-md`) colored `#64748B`, followed by company title, role, and bulleted accomplishments.

### Input Fields & Contact Elements
- Neutral light field background (`#FFFFFF`), `1px` border (`#CBD5E1`), text `#0F172A`, placeholder `#94A3B8`.
- Height standard `44px`, horizontal padding `0.875rem`, rounded corner `0.5rem`.
- **Focus state:** Clean border color change to `#2563EB` complemented by an unblurred `3px` focus ring: `box-shadow: 0 0 0 3px rgba(37, 99, 235, 0.15)`.

### Code & Terminal Blocks
- Dark Navy interior (`#0B0F19`) nested within sections, bordered in `#1E293B`.
- Header bar includes faux OS window controls (three muted dots) and a path label (`~/portfolio/src`).
- Code text set in `JetBrains Mono` (`13px`) with balanced syntax highlighting using blue, slate, and muted emerald tones.
