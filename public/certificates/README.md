# Certificates Directory

You can place your certificate PDF files in this folder to link them directly without code changes.

### Recommended File Names:
1. `digital-learning.pdf` (for YES4YOUTH Digital Learning)
2. `entrepreneurship.pdf` (for YES4YOUTH Entrepreneurship)
3. `work-readiness.pdf` (for YES4YOUTH Work Readiness)
4. `java-21.pdf` (for Udemy Java 21 Programming Masterclass)
5. `genai-ibm.pdf` (for IBM Generative AI Essentials)
6. `genai-wethinkcode.pdf` (for WeThinkCode GenAI for Software Engineers)

Alternatively, you can use the built-in "Manage Certificate Links & Files" button directly on your website to upload any PDF or paste any official verification URL at any time.
